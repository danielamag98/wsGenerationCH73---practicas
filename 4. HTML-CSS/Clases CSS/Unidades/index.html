El modelo de caja (controlando la visualizacion de la caja) --> DISPLAU: INLINE, DISPLAY: BLOCK, DISPLAY:INLINE-BLOCK los elementos inline: pueden comenzar en cualquier lugar de una linea existente. las propiedades de altura y ancho no tienen efecto. elemento block comeinza en una nueva linea y ocupa todo el ancho de la caja. puede contener otros leementos de tipo block o inline inline-block, es un elemento que se muestra en linea pero se puede definir su altura y ancho
